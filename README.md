# number guessing game in c

a simple number guessing game made using c programming.

## how to play
- guess the secret number between 0 and 20.
- you get 5 attempts to guess the correct number.
- the game tells you if your guess is correct.

## language used
- c

## what i learned
- using variables
- taking user input
- using loops and conditional statements
